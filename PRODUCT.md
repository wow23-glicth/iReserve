# PJP Hardware

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The existing application serves Admin, Manager, and Cashier staff. It manages a hardware store's stock, sales, and reservations. The user confirmed balanced UX attention across all screens.

## Product Purpose

Keep inventory visible, record multi-product checkouts, print receipts, manage reservation status, and understand sales performance.

## Capabilities and Constraints

Existing React, TypeScript, Vite, Supabase, Chart.js, and Lucide implementation. Preserve authentication, role restrictions, database contracts, grouped sales, printable receipts, exports, inventory CRUD, reservation actions, and staff administration. UI validation with synthetic fixtures must be distinguished from live database validation.

## Brand Commitments

Preserve PJP HARDWARE and its existing logo. The user supplied a binding forest-green and warm-ivory reference for login, dashboard, inventory, sales, reservations, and analytics and requested a complete UI/UX redesign with iterative verification.

## Evidence on Hand

Existing source and logo in frontend/public/logo2.png. Reference supplied September 8, 2026. Display operational values from records; never invent growth percentages. Device-specific physical usage has not been confirmed; desktop counter use and mobile access are design assumptions.

## Product Principles

- Make daily tasks easy to locate and scan.
- Preserve business behavior while improving navigation and interaction.
- Use readable, responsive, keyboard-accessible controls.
- Show honest empty, loading, and error states.
